**Har listing mein dhyan rakhein:**
1. Website field mein **https://powerrun.in** zaroor daalein. Yahi backlink hai, aur SEO ke liye yahi chahiye.
2. Naam, pata aur phone **upar wali table se hi** copy karein. Ek bhi spelling alag na ho, jaise "Kasganj" ki jagah "Kasgang" nahi.
3. Logo `assets/powerrun-logo.png` aur cover photo `youtube/powerrun-youtube-banner.png` use karein.
4. Jo listing ban jaye, uska link mujhe bhej dena. Main use website ke schema (`sameAs`) mein jod dunga, taaki Google samjhe ki ye sab ek hi company ke profile hain.
5. Kisi bhi directory ka "paid package" lene ki zaroorat nahi. Free listing se hi backlink mil jata hai.
